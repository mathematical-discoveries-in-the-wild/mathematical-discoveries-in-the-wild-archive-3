# arXiv:1406.4025 Grushin topological-dimension conjecture - literature answer

Status: `literature_already_answered (full affirmative)`

Original source:

- Peng Chen and El Maati Ouhabaz, *Weighted restriction type estimates for
  Grushin operators and application to spectral multipliers and Bochner-Riesz
  summability*, arXiv:1406.4025; Math. Z. 282 (2016), 663-678.
- Exact location: the unnumbered Conjecture immediately after Theorems 1.1 and
  1.2, arXiv PDF page 3.

Answering source:

- Lars Niedorf, *A p-specific spectral multiplier theorem with sharp
  regularity bound for Grushin operators*, arXiv:2110.10058; Math. Z. 301
  (2022), 4153-4173.
- Exact location: discussion immediately before Theorem 1.1 and Theorems 1.1
  and 1.2, arXiv PDF page 3.

Chen-Ouhabaz conjecture that the factor
`D=max(d1+d2,2d2)` in both of their displayed results can be replaced by the
topological dimension `d1+d2`. Niedorf explicitly identifies this expectation,
cites the Chen-Ouhabaz paper, and proves the replacement. Theorem 1.1 gives the
sharp p-specific multiplier regularity for `1<p<=p_(d1,d2)`, and Theorem 1.2
gives the matching Bochner-Riesz bound for `1<=p<=p_(d1,d2)`. The original
paper already records the multiplier endpoint `p=1` as known, so the stated
conjecture is fully resolved.

This is exact literature retrieval, not a new mathematical result. It does not
claim anything beyond the p-range and the two conclusions in the source
conjecture.
