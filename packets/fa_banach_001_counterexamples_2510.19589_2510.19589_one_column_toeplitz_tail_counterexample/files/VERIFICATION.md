## Exact-target check

Section 13, page 41 of arXiv:2510.19589 asks whether the stated operator-valued
`BMO^1_alpha` hypotheses and the single condition `||T_b Q_d|| -> 0` force

## Proof audit

1. **Sector construction.** Pairwise disjoint relatively open caps exist on
   the unit sphere. Their radial sectors are measurable and disjoint.
2. **Kernel concentration.** For a boundary point `zeta`, the measures
   `|k_{r zeta}|^2 dnu_alpha` converge to the point mass at `zeta`. The packet
   proves this directly by uniformly bounding the kernel off any neighborhood
   of `zeta`; no unproved localization theorem is used.
3. **Scalar norms.** Positivity gives
   `<T_{chi_E} k_a,k_a> = tilde(chi_E)(a)`. Kernel concentration makes the
   supremum one, while `||T_{chi_E}|| <= 1`, hence each scalar component has
   norm exactly one.
4. **Symbol spaces.** At each point the rank-one symbol is either zero or a
   matrix unit. Both it and its adjoint have uniformly bounded norms as maps
   from `ell^2` into `ell^1 cap ell^2`. Their ranges are countable, so strong
   measurability is immediate. Every bounded Banach-valued symbol lies in the
   paper's `BMO^1_alpha` class by the defining integral estimate.
5. **Berezin transform.** The transform coefficients are nonnegative numbers
   `p_j` with `sum_j p_j <= 1`; therefore the transformed column has uniformly
   bounded `ell^1`, hence `ell^2`, norm.
6. **One-sided tail.** The symbol annihilates every input vector orthogonal to
   `e_1`, so `T_b Q_d = 0` for all `d >= 1`.
7. **Failure of the opposite tail.** Every tail contains a scalar component
   `T_{chi_E_j}` of norm one, so `||Q_d T_b|| = 1`.
8. **Algebra obstruction.** Each finite sum of finite products generated by
   finite-matrix symbols has finite row and column support. Operator-norm
   closure therefore forces both tail norms to tend to zero. The constructed
   operator violates this necessary condition.

## Edge cases and scope

- The construction works for every `n >= 1` and `alpha > -1`.
- It uses bounded symbols, stronger than the integrability assumed in the
  question.
- With the standard sum or maximum norm on `ell^1 cap ell^2`, all displayed
  bounds are uniform; changing to an equivalent intersection norm changes only
  harmless constants.
- No assertion is made about a strengthened question that assumes both
