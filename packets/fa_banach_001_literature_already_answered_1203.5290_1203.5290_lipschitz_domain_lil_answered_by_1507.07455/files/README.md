# Lipschitz-domain oscillation LIL - literature answer

Status: `literature_already_answered` for the Lipschitz-domain branch of the
concluding questions in arXiv:1203.5290.

The source asks on PDF page 19, Section 5, whether its oscillation LIL extends
to Lipschitz domains. Pavel Mozolyako's arXiv:1507.07455 explicitly cites the
source result, says its main goal is this extension, and proves it as Theorem 1
on supporting PDF page 2.

Important scope limit: the source's separate radial-only local conjecture is
not answered by the supporting paper. Its Theorem 2 assumes non-tangential
control, and supporting PDF page 3 explicitly says that replacement by radial
control remains unknown.

The review artifact is `solution_packet.pdf`; LaTeX intermediates and rendered
QA pages live in `tmp/`.
