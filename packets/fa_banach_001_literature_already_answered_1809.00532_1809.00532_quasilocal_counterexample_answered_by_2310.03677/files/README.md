# Quasi-local counterexample — literature answer

Status: `literature_already_answered`

Question 6.7 of Špakula–Zhang, arXiv:1809.00532, asks whether a
bounded-geometry space can carry a quasi-local operator on ℓ² outside its
uniform Roe algebra. Ozawa's arXiv:2310.03677 answers yes: for every uniformly
locally finite space containing a sequence of expanders, Corollary C proves
that the uniform Roe algebra is properly contained in the quasi-local algebra.
