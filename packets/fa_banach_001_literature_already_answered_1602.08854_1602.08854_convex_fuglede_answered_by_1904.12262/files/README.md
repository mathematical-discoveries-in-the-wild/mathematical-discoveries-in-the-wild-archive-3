# Convex Fuglede problems answered by arXiv:1904.12262

Status: `literature_already_answered`

## Source problems

Rachel Greenfeld and Nir Lev, *Fuglede's spectral set conjecture for convex
polytopes*, arXiv:1602.08854, Section 17, printed page 38, pose:

- Problem 17.1: prove that every spectral convex polytope in dimension at
  least four tiles by translations.
- Problem 17.3: prove the same assertion for zonotopes in dimension at least
  four.
- Problem 17.4: prove that every spectral convex body is a polytope.

## Later answer

Nir Lev and Mate Matolcsi, *The Fuglede conjecture for convex domains is true
in all dimensions*, arXiv:1904.12262, Theorem 1.1, prove that in every
dimension a spectral convex body is a convex polytope and tiles face-to-face by
translations along a lattice. This simultaneously answers Problems 17.1,
17.3, and 17.4. The later paper cites the source as the previous
three-dimensional polytope result and explicitly presents its theorem as the
all-dimensional, general-convex-body completion.

The result appeared in *Acta Mathematica* 228 (2022), 385-420,
doi:10.4310/ACTA.2022.v228.n2.a3.
