# Problems A-C in finite-dimensional dilation theory - literature answers

Status: `literature_already_answered` for Problems A, B, and C of arXiv:1012.4514.

Levy and Shalit's source paper poses four labeled questions. Three have exact later answers:

- Problem A (source PDF page 7) asks whether a commuting tuple of contractive `3 x 3` matrices can violate the scalar multivariable von Neumann inequality. Knese, arXiv:1508.06488, Theorem 1.2 on supporting PDF page 2, proves that every such tuple satisfies the inequality. The answer is no.
- Problem B (source PDF page 8) asks whether Brehmer's positivity inequalities are equivalent to finite-dimensional regular unitary `N`-dilations for every `N`. McCarthy-Shalit, arXiv:1105.2020, Theorem 1.7 and Corollary 1.8 on supporting PDF page 4, prove exactly this equivalence. The answer is yes.
- Problem C (source PDF page 9) asks whether every pair of commuting finite-dimensional contractions has a finite-dimensional unitary `N`-dilation. McCarthy-Shalit Theorem 1.2, stated on supporting PDF page 2, proves the stronger result that every finite-dimensional commuting tuple possessing a unitary dilation has such an `N`-dilation. Ando's theorem supplies the dilation for pairs. The answer is yes.

Problem D is deliberately not classified as answered. It asks vaguely for a finite-dimensional commutant-lifting analogue. McCarthy-Shalit explain that the appropriate formulation is unclear and give a counterexample to lifting through one particular Halmos `1`-dilation, but this does not settle every plausible existential formulation.

The compact review artifact is `solution_packet.pdf`. The source and two decisive supporting papers are included.
