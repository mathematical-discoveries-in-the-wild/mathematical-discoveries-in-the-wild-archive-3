# Bidual invariance of Whitley thickness: already answered

Status: `literature_already_answered`.

The final question of arXiv:1307.4385 asks whether Whitley's thickness always
satisfies `T(X)=T(X**)`. The later paper arXiv:1402.0996 answers negatively on
PDF page 8:

```text
T(C[0,1]) = 2, while T(C[0,1]**) = 1.
```

The supporting authors explicitly say that this example answers the question
in the source paper. This is therefore an exact literature answer, not a new
result of the present run.
