# The p<2 Hardy-space extension was answered by arXiv:2001.10021

Status: `literature_already_answered`

## Original future-work problem

Richard D. Carmichael, Stevan Pilipovic, and Jasson Vindas, *Vector valued
Hardy spaces related to analytic functions having distributional boundary
values*, arXiv:1801.06709 (published in 2019), Section 5, PDF page 20.

The authors propose using Banach spaces of Fourier type `p` to extend
Theorems 4.2--4.4 from `2 <= p <= infinity` to `1 <= p < 2`.

## Explicit later answer

The same authors' separate paper *Note on vector valued Hardy spaces related
to analytic functions having distributional boundary values*,
arXiv:2001.10021 (2020), explicitly identifies the 2019 paper and its Theorem
4.4. Its introduction says the aim is to improve that theorem to every
`1 <= p <= infinity` and every Banach space. Theorem 1 proves exactly this,
including the Hardy-space conclusion and Poisson representation.

This is strictly stronger than the proposed Fourier-type extension: no
Fourier-type assumption is needed.
